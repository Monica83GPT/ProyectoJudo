# Pendientes del proyecto

Este fichero guarda las ideas, tareas y recordatorios que el usuario pida apuntar para hacer despues.

## Pendientes

- Hacer HTML inicial.
- Ver este video: https://www.youtube.com/watch?v=EpJGNZ_F104
- Guardar el proyecto en GitHub con `git add`, `git commit` y `git push`.
- Guardar un resumen del trabajo en `PENDIENTES.md` o `CONTEXTO.md`.
- Mañana, en el otro PC, ejecutar `git pull` para descargar los cambios.
